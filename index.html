CV Fit: tailor a CV to any job posting

AI web app · live · Nov 2026

I was rewriting my CV for every application, so I built a tool to do the heavy lifting. Paste a job posting and CV Fit shows which skills your CV already proves, flags the gaps, and rewrites the CV for that role.

  • Instant keyword check against 40+ analyst skills, with the posting highlighted
  • Claude API rates each requirement as strong, partial or a gap, with evidence from the CV
  • Builds a full tailored CV and exports it as a one-page Word file
  • Guardrail in the prompt: rewrites may only use facts already in the CV

JavaScript · Claude API · Prompt design · Vercel serverless · Word export
